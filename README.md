# Stickers 💖

**Express more with cute stickers.** An iOS app (SwiftUI) with 6 sticker categories and
93 stickers. You can copy, paste, drag or share any sticker into WhatsApp, iMessage
and other chat apps. The project also includes an iMessage sticker app and an
"Add to WhatsApp" import for each category.

| Category | Stickers |
|---|---|
| Love | 20 (from your two Love sticker sheets) |
| Friendship | 11 (your own artwork) |
| Sisters & Siblings | 15 |
| Family Love | 15 |
| Feelings & Emotions | 16 |
| Self-Love & Self-Care | 16 |

---

## 1. Run it in Xcode

**Requirements:** a Mac with Xcode 15 or newer. The app runs on iOS 16 or newer (iPhone and iPad).

1. Open `Stickers.xcodeproj`.
2. Select the **Stickers** project, then the **Signing & Capabilities** tab.
3. Choose your **Team** for **both** targets: `Stickers` and `StickersMessages`.
4. The bundle identifiers are already set:

   | Target | Bundle identifier |
   |---|---|
   | `Stickers` (app) | `com.regina.stickers` |
   | `StickersMessages` (iMessage extension) | `com.regina.stickers.MessagesExtension` |

   The extension ID must always start with the app ID.
5. Pick the **Stickers** scheme and a device, then press **Run** (⌘R).

> To test WhatsApp, use a real iPhone with WhatsApp installed. WhatsApp is not
> available in the Simulator.

## 2. How people use it

| Action | What happens |
|---|---|
| Tap a category | Opens all stickers in that category. |
| Tap a sticker | Copies it as a transparent PNG. Paste it in any chat. |
| Touch, hold and drag a sticker | Drops it into another app. On iPhone, keep holding and switch apps with your other hand. On iPad, use Split View. |
| Touch and hold → **Share…** | Opens the share sheet (WhatsApp, Messages, Instagram, Telegram and more). |
| **+** button → **Add to WhatsApp** | Adds the whole category to WhatsApp as a real sticker pack. |
| **+** button → **Use in iMessage** | Shows how to open the Stickers app inside Messages. |
| Search bar | Finds stickers by name, word or emoji (for example *love*, *hug*, *mom*, 😂). |

**In iMessage:** open a chat → tap **+** → **More** → **Stickers**. Pick a category,
then tap a sticker to send it, or drag it onto any message bubble (peel and stick).

## 4. Add or change stickers

All sticker images are generated by one script, so sizes and limits are always right.

```bash
pip3 install Pillow numpy scipy
python3 Tools/generate_assets.py
```

Edit the `PACKS` list at the top of `Tools/generate_assets.py`:

- `emoji("Teddy bear", "🧸", "Teddy Bear", "bear hug cute")` uses a Fluent Emoji picture.
- `text("Love\nYou", "❤️", "Love You", "love", style="heart")` draws a text sticker.
- `art((x1, y1, x2, y2), "🤗", "Name")` cuts a picture out of `Design/LandingPage-reference.png`.
- `png("Friendship/01-bff-girls.png", "👭", "BFF Girls", "bff", label="BFF")` uses one sticker
  drawn on a transparent background (any size; it is cleaned, bordered and scaled to 512).
- `sheet("Love-sheet-1.png", 0, "❤️", "Love You", "love", label="Love You")` cuts sticker
  number 0 (reading order, 10 per sheet) out of a sticker sheet in `Design/`.

The script checks every limit below and stops with an error if one is broken.
No Swift change is needed: the app reads `catalog.json`.

## 5. Limits this project follows (from the official sources)

| Rule | Value | Source |
|---|---|---|
| WhatsApp sticker size | exactly 512 × 512 px | [WhatsApp stickers iOS README](https://github.com/WhatsApp/stickers/tree/main/iOS) |
| WhatsApp static sticker file | WebP, ≤ 100 KB | same |
| WhatsApp tray icon | PNG, 96 × 96 px, ≤ 50 KB | same |
| Stickers per WhatsApp pack | 3 to 30 | same (`Limits.swift`) |
| Emojis per sticker | up to 3 | same |
| Import method | JSON on pasteboard type `net.whatsapp.third-party.sticker-pack`, then open `whatsapp://stickerPack` | same (`Interoperability.swift`) |
| iMessage sticker file | PNG/APNG/GIF/JPEG, < 500 KB, 300–618 px | [Apple: `MSSticker init(contentsOfFileURL:localizedDescription:)`](https://developer.apple.com/documentation/messages/mssticker/init(contentsoffileurl:localizeddescription:)) |
| iMessage app icon sizes | 27×20, 32×24, 60×45, 67×50, 74×55, 1024×768 pt | [Apple: Messages Extension Icon Type](https://developer.apple.com/library/archive/documentation/Xcode/Reference/xcode_ref-Asset_Catalog_Format/MessagesIconType.html) |

`COMPRESS_PNG_FILES` is turned off, so Xcode copies the PNG files unchanged.
WhatsApp warns that Xcode's PNG optimization can break its size limits.

## 6. Good to know

- **Pasted or shared stickers arrive as pictures.** WhatsApp and iMessage show a
  copied PNG as an image message. To send a *real* sticker, use **Add to WhatsApp**
  (WhatsApp sticker tray) or the **Stickers iMessage app** (peel and stick).
- **Before the App Store:**
  - Fill in `iOSAppStoreLink` in `WhatsAppStickerService.swift`.
  - Add the keyword `WAStickers` in App Store Connect, so WhatsApp can list your app.
  - Your bundle ID must not contain `WA.WAStickersThirdParty`.
- **Artwork credits** are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md):
  Microsoft Fluent Emoji (MIT) and the Fredoka font (OFL). The character
  pictures, the 20 Love stickers and the 11 Friendship stickers come from your own designs.
